# todo-list

A Django based todo list ap

## Quickstart

```shell
git clone https://github.com/misha-cw/todo-list
cd todo-list
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
